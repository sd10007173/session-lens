## 設計決定

產品用途是本機對話紀錄瀏覽、篩選及專案歸屬設定。主要內容是 session 表格，不增加儀表板卡片或介紹區塊。

- 白底 #ffffff；正文 #253244；輔助文字 #667085；分隔線 #e5e9ef；表頭底色 #f6f8fb；操作及焦點 #245fc0。
- 中文用本機 PingFang TC / Noto Sans TC，標題優先 Avenir Next。24px 標題、14px 內文、12–13px 標籤與資料。不載入遠端字型。
- 左對齊標題與描述，右上角保留次要的設定專案入口；下方是篩選欄及表格。窄螢幕只在資料表區域橫向捲動。

```text
Session Lens                                      設定專案
共 … 個 session，目前顯示 … 個，過濾後大小 …。
日期 / 分類 / 專案 / 搜尋                  重設 / 重新掃描
開始 | 最後活動 | 專案 | …
```

原先的數量卡片、彩色分類膠囊與對話氣泡框會和操作元件混淆。本版改用文字、留白與分隔線，邊框主要表達輸入欄位或操作；不加入裝飾性大標題或動畫。

專案彈窗保留空白起點；編輯採逐列配置，左側名稱、右側多路徑、列尾刪除，欄名僅顯示一次。新增接在清單下方，空白路徑從單行開始，隨多行輸入增高。已匯入路徑預設收合，搜尋不分大小寫，只過濾路徑列表，不更動專案草稿或原始資料；結果保留 Session 數降冪，欄位為專案路徑、Session 數、操作。

## 本輪驗收

透過本機 8920 網頁，以真實索引驗證 CoinKarma 搜尋、降冪、無結果與清除、複製和 session 展開；1440px 桌面與 390px 窄螢幕檢查溢出及截圖。此驗收證明操作與版面，不代表同仁已認可視覺設計。後續調整仍以 Wayne 使用回饋為準。
